Inscrição no Workshop de Desenvolvimento Mobile

Último exercício da semana: o formulário já existe no HTML. O JavaScript vai criar o que ainda não está na página.

O que você vai decidir

O maior erro desta semana é usar a ferramenta errada na hora de criar elemento. Use esta regra:

  • createElement — o elemento precisa nascer no JavaScript: vem de um array, vai receber clique, ou você precisa guardar a referência para usar depois.
  • innerHTML — um container já existe e você só quer preencher o visual (títulos e parágrafos). Cuidado: ele apaga tudo que estava dentro.
  • textContent — só texto, sem tag HTML.
  1. Preencha o <select> das trilhas a partir do array, com createElement.
  2. Crie a seção de resumo com createElement — ela não existe neste HTML.
  3. No submit, recupere os dados com new FormData(formulario): .get() para campo único e .getAll() para os temas. Depois monte o resumo com innerHTML.
  4. O botão Fazer nova inscrição deve nascer com createElement e addEventListener. Não coloque esse botão dentro do innerHTML.
